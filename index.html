TL;DR

Can a frozen VLM keep learning crops, weeds and pests?

Hypothesis
If retrieval already finds the right class, a frozen vision-language model with a small external memory should be able to keep learning new agricultural classes from five images each, and agentic verification should help it decide.
TL;DRRetrieval finds the class (80% top-3), but the model's own choice collapses (43%). Agentic verification does not repair it. Packing more, smaller references into the same 128 KiB helps where the budget binds: +25 points on IP102 (pHolm = 0.008), and nowhere on few-class sets.
Abstract

Abstract

CLOVE asks whether a small, locally runnable vision-language model can itself be the classifier when agricultural categories are released over time with five labelled images each, while images of never-taught categories keep arriving. Frozen Qwen2.5-VL-3B-Instruct chooses a released class or UNKNOWN; nothing is trained and only a 128 KiB external memory changes. On DeepWeeds development data the true class is in the memory index's top three for 80% of images, but the model's forced choice is right for 43%. In a pre-registered confirmation on never-examined image groups, exhaustive class verification is not confirmed and retrieve-then-verify is not confirmed. A byte-optimised dense memory with retrieve-then-verify (CLOVE-D12) meets the pre-registered rule on 1 of 8 data sets, is lower on 4 and otherwise indistinguishable. Frozen-feature readouts remain stronger in closed-set accuracy. Every arm, including every failed one, is reported.

Discussion

What this means

For agricultural deployment

A small local VLM can absorb new crop, weed and pest classes without training, but only while few classes are known. Beyond that, its multiple-choice decision becomes the weak link even with the right evidence in memory.

What did and did not work

  • Agentic inspection and per-class verification: not confirmed, one confirmed loss.
  • Denser memory: confirmed where many classes compete for 128 KiB (IP102).
  • Frozen-feature readouts remain the stronger closed-set reference.

Limitations

  • Small query sets; one primary class order.
  • One 3B model in fp16.
  • Many-class hypothesis formed after IP102; tested further on iNatAg-100, PlantDoc, PlantVillage and IP102-96 (running).
